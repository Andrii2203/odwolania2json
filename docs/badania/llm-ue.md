# Дослідження LLM-провайдерів у ЄС (до ADR-0004)

Дата: 2026-11-21

## Вимоги UZP
1. **Модель:** тільки з відкритими вагами (open-weight), яку можна розгорнути локально, з **ліцензією без комерційних обмежень** (`Apache 2.0` або `MIT`).
   > **Важливо:** моделі з кастомними ліцензіями (*Llama Community License*, *Mistral Research / Non-Production License* для Codestral чи Large) виключаємо, щоб уникнути юридичних ризиків на оцінюванні.
2. **Інфраструктура:** і компанія-оператор API, і дата-центри — **в ЄС** (відповідність GDPR, відсутність юрисдикції US CLOUD Act).
3. **Приватність:** дані запитів не повинні використовуватися для донавчання моделей.
4. **Інтеграція:** OpenAI-сумісний REST API (`/v1/chat/completions`), щоб перемикати провайдера лише через змінні оточення (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`).

## Детальний огляд провайдерів

### 1. Mistral AI (La Plateforme / Mistral Studio)
- **Юрисдикція та сервери:** Mistral AI SAS (Париж, Франція). Інференс за замовчуванням для європейських акаунтів та ендпойнта `api.mistral.ai` виконується в дата-центрах у ЄС.
- **Моделі з ліцензією Apache 2.0:**
  - `mistral-small-2503` / `mistral-small-3.1-24b-instruct` (та актуальний аліас `mistral-small-latest`, 24B параметрів, контекст 128k) — ліцензія **Apache 2.0**.
  - `ministral-3b-latest`, `ministral-8b-latest`, `ministral-14b-latest` (сімейство Ministral 3) — ліцензія **Apache 2.0**.
  - `open-mistral-nemo` (12B) — ліцензія **Apache 2.0**.
  - *(Увага: `mistral-large-latest` та `codestral-latest` мають обмежені ліцензії — їх не використовуємо).*
- **Ціна за 1 млн токенів:**
  - `Ministral 3B`: $0.10 вхід / $0.10 вихід.
  - `Ministral 8B`: $0.15 вхід / $0.15 вихід.
  - `Ministral 14B`: $0.20 вхід / $0.20 вихід.
  - `Mistral Small (24B)`: $0.15 вхід / $0.60 вихід (кешований вхід — $0.015).
- **Безкоштовний ліміт та навчання на даних:**
  - Безкоштовний план (**Free Tier / Experiment**) доступний одразу після реєстрації, але має обмеження ~1 запит/с (RPS) і **використовує промпти для навчання моделей за замовчуванням**.
  - На платному плані (**Scale / Pay-as-you-go**) дані **не використовуються** для навчання, ліміт швидкості зростає, а в панелі `admin.mistral.ai` можна виставити жорсткий місячний ліміт витрат у євро/доларах (наприклад, €5 для ключа журі).
- **OpenAI SDK:** Повністю сумісний (`base_url="https://api.mistral.ai/v1"`).
- **Посилання:**
  - Ціни та моделі: https://mistral.ai/pricing/
  - Документація моделей і ліцензій: https://docs.mistral.ai/getting-started/models/models_overview/

## Оцінка витрат на прогін і здачу

Припустимо, що правила покривають більшість полів, а LLM викликається лише як fallback для складних полів `odwolanie` (наприклад, до 4000 вхідних токенів і 500 вихідних токенів на документ):
- **1 прогін на 60 тренувальних справах (~60 відкликань):** ~240 тис. вхідних + 30 тис. вихідних токенів ≈ **€0.05 ($0.05)** на `Mistral Small 24B`.
- **Оцінка журі (10–30 прихованих справ):** менше **€0.02**.
- Навіть 100 повних прогонів коштуватимуть лише **~€5**.

## Рекомендація для проєкту (ADR-0004)

1. **Модель за замовчуванням:** **`Mistral Small 3.1 / 3.2 (24B Instruct)`** (ліцензія **Apache 2.0**, відмінна польська мова та витягування JSON за схемою).
2. **Основний провайдер для ключа здачі:**
   - **Варіант А (найпростіший старт і жорсткий ліміт бюджету):** **Mistral AI (`api.mistral.ai/v1`)** на **платному плані Pay-as-you-go** (щоб гарантувати *Zero Training on Data* і високі rate limits) з окремим API-ключем і виставленим лімітом витрат €5–€10 у консолі.
   - **Варіант Б (резервний, 100% Zero Data Retention з коробки):** **Scaleway (`api.scaleway.ai/v1`)** або **OVHcloud (`oai.endpoints.kepler.ai.cloud.ovh.net/v1`)** з тією самою моделлю `mistral-small-3.2-24b-instruct`.
3. **Локальна модель на RTX 5060 (8 ГБ VRAM) для безкоштовних прогонів під час розробки:**
   - Через **Ollama** (`http://localhost:11434/v1` — той самий OpenAI-сумісний інтерфейс без зміни коду):
     - `ministral-3:8b` або `qwen2.5:7b-instruct` / `qwen3:8b` (Apache 2.0, у квантуванні `Q4_K_M` займає **~5.2–5.8 ГБ VRAM**, працює повністю у відеопам'яті RTX 5060 зі швидкістю ~60–90 токенів/с).
   - Це дозволяє відлагодити промпти і JSON-схему безкоштовно локально, а фінальний замір F1 і здачу зробити з ключем `Mistral Small 24B` в ЄС.
