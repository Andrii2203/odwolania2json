# ADR-0007: OCR для сканів

Статус: прийнято, 2026-11-21 (за `docs/badania/ocr.md`)

## Контекст
На стенді UZP: тестові документи переважно цифрові PDF, але скани теж можуть бути. Скан без OCR = порожній текст → тип не визначено → усі поля документа втрачені. ПК журі — без GPU, встановлення лише через `pip`.

## Рішення
```
сторінка PDF → pypdf дав текст? → так: беремо його
                                → ні (< 40 символів): pypdfium2 рендерить сторінку → RapidOCR читає
```
- **`pypdfium2`** (Apache 2.0 / BSD) — рендер сторінки в картинку, без Poppler.
- **`rapidocr` + `onnxruntime`** (Apache 2.0), модель PP-OCRv5 `latin` — знає `ą ć ę ł ń ó ś ź ż`.
- OCR лише там, де немає тексту: цифрові PDF не сповільнюються.

## Розглянуті варіанти
- **Tesseract:** потрібна окрема програма на ПК журі → падіння, якщо її немає.
- **docTR:** тягне PyTorch (~1 ГБ), слабкий з польськими літерами з коробки.

## Наслідки
- +~200 МБ залежностей. Моделі (~20 МБ) завантажуються при першому запуску; вирішимо при реалізації, чи класти їх у репо.
- Тест: справжній PDF, перетворений на «скан» (лише картинка), має дати той самий тип документа.
